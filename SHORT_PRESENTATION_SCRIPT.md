# 🎤 FreshFind - 2-Minute Presentation & Viva Script (Simple & Easy)

> Yeh script bilkul simple aur natural Roman Urdu + English mein hai taake 1st semester student asani se judges ke samne bol sake.

---

## 🌟 Presentation Kaise Shuru Karein (Opening)

*"Respected Judges & Sir,*  
*Hamara project **FreshFind** hai jo humne Aptech Techwiz 7 ke theme **eGreen Basket** ke liye banaya hai.*  
*Yeh ek **Single Page Application (SPA)** hai jo humne purely **React.js** mein develop ki hai.*

*Problem yeh thi ke hamare shehar mein local farmers markets kab lagte hain aur kahan lagte hain, uski timing logon ko pata nahi hoti. Humne yeh website banayi hai taake log asani se apne qareeb ke markets dhoond sakein aur taaza, seasonal fruits aur vegetables khareed sakein."*

---

## 💻 Website Ke 5 Main Features (Screen Demo Ke Sath Dikhao)

### 1. Home Page & Quick Find
- Screen par search bar dikhayein:
  *"Sir, yeh hamara Quick Find filter hai. Yahan se user area ya day of week select kar ke search kar sakta hai."*

### 2. Market Directory & Live 'Open Now'
- Card par glowing green badge dikhayein:
  *"Sir, website mein real-time clock hai jo market ke opening aur closing time se compare karta hai. Agar market is waqt khula ho to yeh live **'Open Right Now'** badge show karta hai."*

### 3. Market Details & Embedded Map
- Kisi bhi market par click karein:
  *"Yahan market ka weekly schedule table hai jisme aaj ka din highlight hota hai, Google Map hai, aur wahan milne wali vegetables ki list hai."*

### 4. Product Guide & Seasonal Calendar
- Product Guide aur Seasonal tab dikhayein:
  *"Yeh hamara Seasonal guide hai jo theme **eGreen Basket** ko cover karta hai. User dekh sakta hai ke is season mein kaunse fruits taaza hain aur unke health benefits kya hain."*

### 5. Offline AI Chatbot & Bookmarks
- Niche bot icon aur Saved button par click karein:
  *"Sir, competition ke SRS ke mutabiq humne bina kisi external paid API ke **offline rule-based chatbot** banaya hai jo JSON data se jawab deta hai. Aur user apni pasandida markets ko save kar ke apna personal note bhi likh sakta hai aur text file download kar sakta hai."*

---

## ❓ Judges Ke 3 Common Sawalat Aur Unke Asan Jawab

**Q1: "Aapne backend (Node.js/Database) kyu use nahi kiya?"**  
👉 **Jawab:** *"Sir, SRS ke Section 1.5 mein clearly likha tha ke portal ko bina kisi server backend ke banana hai. Is liye humne sara data JSON files (`markets.json`, `produce.json`) mein store kiya hai."*

**Q2: "Chatbot kaise kaam kar raha hai?"**  
👉 **Jawab:** *"Sir, humne `chatbot.json` mein keywords aur questions pehle se set kiye hain. Jab user sawal poochta hai, to hamara code keyword match kar ke sahi jawab aur button screen par dikhata hai."*

**Q3: "Bookmarks kahan save ho rahe hain?"**  
👉 **Jawab:** *"Sir, bookmarks aur personal notes browser ke `localStorage` mein save hote hain, is liye page refresh karne par bhi delete nahi hote."*
